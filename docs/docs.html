Guia Rápido para Usuários

Seja bem-vindo à ZIPPY! Aqui você encontrará tudo o que precisa para começar a usar a plataforma de forma simples e eficiente.

  1. Faça Login: Use seu email para acessar a ZIPPY. Se ainda não tem conta, será redirecionado para criar uma facilmente.
  2. Envie Mensagens: Digite sua pergunta ou comando na barra inferior e pressione Enter ou clique no botão de envio.
  3. Ative a Pesquisa na Web: Clique no ícone de globo () localizado na barra inferior, próximo ao campo de texto, para que a IA busque informações atualizadas na internet, garantindo respostas mais precisas.
  4. Crie Imagens: Digite /imagem seguido da descrição da imagem que deseja criar. Exemplo: /imagem um cachorro brincando na praia. Envie a mensagem para gerar a imagem.
  5. Envie Imagens para Análise: Use o botão de imagem () localizado na barra inferior, ao lado do botão de pesquisa na web, para selecionar uma foto do seu dispositivo. Após selecionar, digite uma pergunta relacionada à imagem, como "O que tem nesta foto?", e envie para receber a análise da IA.
  6. Gerencie seu Histórico: Todas as conversas ficam salvas para você consultar depois. Pode limpar o histórico nas configurações quando quiser.
  7. Personalize a Experiência: No menu de configurações, altere o tema, veja seu tipo de conta, limpe histórico ou desconecte-se.
  8. Receba Notificações: A ZIPPY informa sobre erros, confirmações e outras mensagens importantes para você.

Explore, experimente e aproveite tudo o que a ZIPPY tem a oferecer para facilitar seu dia a dia!

Guia Técnico para Desenvolvedores

Esta seção é destinada a desenvolvedores e colaboradores que desejam entender a arquitetura, funcionamento e integração da ZIPPY.

Arquitetura Geral

A ZIPPY é uma aplicação web SPA (Single Page Application) construída com HTML, CSS (Tailwind CSS) e JavaScript puro. Ela se comunica com APIs externas para fornecer funcionalidades avançadas de chat, geração e análise de imagens.

Componentes Principais

  • Interface do Usuário: Estruturada em HTML sem frameworks JS, estilizada com Tailwind CSS para responsividade e temas claro/escuro.
  • Gerenciamento de Estado: Controlado via variáveis JS, manipulando estados como modo imagem, ativação da pesquisa na web, e controle de envio.
  • Armazenamento Local: Utiliza IndexedDB para persistência do histórico, com sincronização via API REST.
  • Comunicação com APIs: Integra com endpoints REST para chat, geração de imagens e análise (API Gemini).
  • Modais e Notificações: Implementados com manipulação direta do DOM, garantindo acessibilidade e controle de foco.
  • Barra de Entrada: Contém o campo de texto para mensagens, botão de ativar pesquisa na web (ícone de globo), botão para seleção de imagens (ícone de imagem) e botão de envio (ícone de avião de papel).

Fluxo de Uso

  1. Login: Usuário é redirecionado para login se não autenticado, com detecção de dispositivo para direcionar para versão mobile ou desktop.
  2. Carregamento do Histórico: Ao entrar, o app carrega mensagens do IndexedDB ou da API, exibindo-as no chat.
  3. Envio de Mensagens: Usuário digita e envia mensagens, que são processadas localmente e enviadas para a API de chat.
  4. Geração de Imagens: Comando /imagem dispara chamada à API de geração, exibindo a imagem retornada.
  5. Análise de Imagens: Imagens enviadas são submetidas à API Gemini com perguntas, e respostas são exibidas.
  6. Atualização do Histórico: Mensagens novas são salvas no IndexedDB e sincronizadas com o servidor.
  7. Configurações: Permitem limpar histórico, alternar tema, desconectar e visualizar dados do usuário.

Detalhes da Barra de Entrada

A barra de entrada é o principal ponto de interação do usuário e contém os seguintes elementos:

  • Campo de Texto: Área para digitar mensagens, comandos ou perguntas. Suporta múltiplas linhas e redimensionamento automático.
  • Botão de Pesquisa na Web: Ícone de globo () que ativa ou desativa a pesquisa na web para respostas atualizadas.
  • Botão de Seleção de Imagem: Ícone de imagem () que abre o seletor de arquivos para envio de imagens para análise.
  • Indicador de Imagem Selecionada: Pequeno ponto verde que aparece sobre o botão de imagem quando uma imagem está selecionada.
  • Botão de Envio: Ícone de avião de papel () que envia a mensagem ou imagem com pergunta.

Acessibilidade e Usabilidade

O código segue boas práticas de acessibilidade, incluindo:

  • Uso de roles ARIA para regiões e alertas.
  • Labels e descrições para botões e inputs.
  • Gerenciamento de foco em modais e notificações.
  • Suporte a navegação por teclado e atalhos.
  • Contraste adequado para temas claro e escuro.

Considerações Técnicas

  • IndexedDB: Usado para armazenar mensagens localmente, com transações para leitura e escrita, e índice por usuário.
  • Retry Fetch: Função utilitária para tentativas automáticas em chamadas API, melhorando robustez.
  • Renderização KaTeX: Aplicada dinamicamente para fórmulas matemáticas nas mensagens.
  • Manipulação DOM: Criação e atualização de elementos para mensagens, imagens, modais e notificações.
  • Eventos: Listeners para botões, inputs, teclado e mudanças de estado.
  • Estilos: Tailwind CSS com customizações para responsividade, temas e animações.

Créditos e Responsabilidades

A API Gemini é responsável pelo processamento das perguntas, geração de respostas e imagens. Eventuais erros ou imprecisões são de responsabilidade da API Gemini. A ZIPPY atua como interface para facilitar a comunicação entre o usuário e a API.
